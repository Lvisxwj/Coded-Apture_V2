# Checkpoint 清单

## Restormer

远端保留 epoch 50、100、150、200、250、300 六个周期 checkpoint，每个约
281 MiB。保存节点的训练统计如下：

| Epoch | 训练 loss | 训练 PSNR (dB) |
|---:|---:|---:|
| 50 | 0.13149128 | 35.14 |
| 100 | 0.12659922 | 35.86 |
| 150 | 0.12311621 | 36.24 |
| 200 | 0.12143392 | 36.45 |
| 250 | 0.11937794 | 36.76 |
| 300 | 0.11846657 | 36.85 |

`restormer_ep300_lr1e-04_bs1.pth` 是已保存节点中训练 loss 最低者。本地副本命名
为 `best_train.pth`，仅用于占位和可视化准备；它不是验证集选择的 best model。
两端文件 SHA-256 均为
`94caeca494dad36903c66e42ae16163472ae6241c34cdb8197ea3f904163fd5e`。

## 其他模型

MST-Mamba、WPO3D、DHM、IFGNet 当前没有可信 checkpoint。任何未来权重必须同时
记录训练配置、代码哈希、选择准则和修订后测试结果，才能标记为可用于论文。
