# Vegindex 代码与产物评估报告

评估日期：2026-06-29。范围仅为 `/data5/SCI/vegindex`；未读取或修改同服务器的
AAAI/CASSI 项目。评估期间未启动 GPU 训练或真实数据推理。

## 1. 数据与环境

- 服务器：4 张 24 GiB GPU 在检查时均有活跃任务，因此禁止占用 GPU。
- Conda 环境：`zwj`，Python 3.7.13。
- 数据：252 个 HSI、252 个 label、1 个 mask，总目录约 110 GB。
- 抽查的 1、15、43、109、200、201、252 均为配对 float32 NPY；HSI 为
  `[H, 1004, 84]`，label 为 `[H, 1004, 32]`。
- 转换文档说明坏 MAT 已在转换时跳过并重新编号，因此活动配置移除了旧的
  `skip_ids=[15,43,109]`。现有 Restormer 权重仍对应旧的 197 场景训练划分。

## 2. 静态代码状态

- 整理前共 51 个 Python 文件，AST 语法检查 51/51 通过。
- 当前只保留 `train.py`、`test.py`、`viz.py` 三个活动入口；整理后活动源码
  32/32 通过服务器 AST 语法检查。
- 已集中 32 通道归一化上下界，避免训练/测试常数漂移。
- 输入归一化改为逐样本执行，不再受同 batch 其他样本的极值影响。
- 测试保存 JSON 原图尺寸；完整叶片拼接后会裁掉反射 padding。
- 测试新增输入、输出、标签的 NaN/Inf 检查和形状检查。

本机 Python 3.12 的 PyTorch 安装无法加载 `shm.dll`，属于本机运行时损坏，不是
项目代码错误。模型 CPU 冒烟改在服务器 `zwj` 环境执行。

## 3. Restormer 占位训练结果

- 参数量日志：24,513,240。
- 训练：300 epoch、batch size 1、共 161.94 小时。
- epoch 300：训练 loss 0.11846657，训练 PSNR 36.85 dB。
- 六个周期权重完整保留；epoch 300 是已保存节点中训练 loss 最低者。
- 本地副本命名为 `best_train.pth`，不能解释为验证集最佳权重。

## 4. 旧测试结果的限制

旧测试日志出现 CRI/ARI 数百量级 L1、负 PSNR 和均值 L1 28.53。代码审计确认旧
`test_unified.py` 对已经处于归一化空间的模型输出再次执行固定通道 min--max，
因此这些数值不能用于论文。历史上出现过 NaN，虽曾通过 max--min 归一化和有限值
检查缓解，但数据、公式分母和模型输出各自的影响尚未分离。

按当前要求，本轮只记录问题，不占用 GPU 深挖，也不把旧测试数值写入论文结论。
GPU 空闲后应使用修订后的 `test.py` 对 epoch 300 权重统一重评。
